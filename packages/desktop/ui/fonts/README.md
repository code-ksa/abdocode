# الخطوط المضمَّنة في القشرة

## Cairo — الوجه العربي للواجهة

`Cairo-Regular.ttf` و`Cairo-Bold.ttf`، بترخيص **SIL Open Font License 1.1**
(نصّه كاملاً في `OFL.txt` بجوارهما، والمنبع
<https://github.com/Gue3bara/Cairo>). الترخيص يبيح إعادة التوزيع ضمن برنامج،
بشرط بقاء إشعاره — ولذلك يُشحن `OFL.txt` مع الملفَّين ولا يُحذف.

**لماذا يُضمَّن ولا يُجلب:** سياسة أمن القشرة `default-src 'self'` (في
`src-tauri/tauri.conf.json`) تمنع أيّ أصلٍ خارجيّ، فخطٌّ من شبكةِ خطوطٍ عامّة
**يُحجب فيسقط النصّ إلى بديلٍ صامت**. ولو سُمح له لصار في كلّ إقلاعٍ نداءٌ
خارجيّ يكشف أنّ هذا الجهاز يشغّل المنتَج — وذلك ما لا نفعله في منتَجٍ يعمل
محليّاً. الخطُّ المضمَّن يعمل بلا شبكةٍ أصلاً، وهذا هو المطلوب.

**لماذا وزنان فقط:** الواجهة تستعمل العاديّ والعريض. كلُّ وزنٍ ‏≈90 كيلوبايت،
فالوزنان ‏≈183، والزيادةُ بلا استعمالٍ حجمٌ يُشحن ولا يُقرأ.

**الصيغة TTF لا WOFF2:** الفرقُ ضغطٌ فحسب، والقشرة تُقرأ من القرص لا من الشبكة
فلا رحلةَ تُوفَّر؛ وتفادي خطوةِ تحويلٍ في البناء يعني أصلاً واحداً لا اثنين.
