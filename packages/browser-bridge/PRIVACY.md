# Abdo Code Bridge — Privacy Policy / سياسة الخصوصية

_Last updated: 2026-09-06 · Publisher: TechnologyKSA (Abdo Code)_

## English

**What the extension does.** Abdo Code Bridge connects the Abdo Code desktop application running on your own computer to the browser tab you are currently viewing. On the application's request it can read the page (text, links, form fields, computed styles), open http/https links you asked for, click, type into non-credential fields, press keys, scroll, and capture a screenshot of the visible tab.

**Data accessed.** Only the content, URL and title of the **active tab**, and only **when a command is issued**. The extension never reads passwords: fields recognised as credentials are refused and handed back to you to type yourself.

**Where data goes.** Exclusively to the Abdo Code application on the same machine, over a local socket bound to `127.0.0.1`. Nothing is transmitted to TechnologyKSA, to Anthropic, to Google, or to any other server. Screenshots are saved on your own disk by the application and never uploaded by the extension.

**Storage.** The extension stores two values in browser storage: the local port and the pairing token you pasted. It does not store page content, history, or cookies.

**Third parties, tracking, sale of data.** None. No analytics, no advertising, no data sale or sharing.

**Your controls.** Remove the token or uninstall the extension at any time; disconnect from Abdo Code → Settings → Connectors. The browser also shows a notice whenever the extension operates a tab.

**Contact.** technoksaweb@gmail.com

## العربية

**ماذا تفعل الإضافة.** تصل تطبيق عبدو كود العامل على جهازك بالتبويب الذي تراه الآن. بطلب التطبيق تقرأ الصفحة (نصّاً وروابط وحقولاً وأنماطاً)، وتفتح روابط http/https التي طلبتها، وتنقر، وتكتب في الحقول غير السرّية، وتضغط مفاتيح، وتمرّر، وتلتقط لقطةً للتبويب الظاهر.

**البيانات التي تصل إليها.** محتوى **التبويب الفعّال** ورابطه وعنوانه فقط، و**عند صدور أمرٍ فقط**. لا تقرأ كلمات المرور أبداً: حقول الاعتماد تُرفض وتُسلَّم إليك لتكتبها بيدك.

**إلى أين تذهب البيانات.** إلى تطبيق عبدو كود على الجهاز نفسه حصراً عبر مقبسٍ محلّيّ على `127.0.0.1`. لا يُرسل شيء إلى تكنولوجيا السعودية ولا إلى أيّ خادم. اللقطات يحفظها التطبيق على قرصك ولا ترفعها الإضافة.

**التخزين.** قيمتان فقط: المنفذ المحلّيّ ورمز الاقتران. لا محتوى صفحات ولا سجلّ تصفّح ولا كوكيز.

**أطراف ثالثة أو تتبّع أو بيع بيانات.** لا شيء من ذلك.

**تحكّمك.** احذف الرمز أو أزل الإضافة متى شئت؛ أو افصل من عبدو كود ← الإعدادات ← الموصّلات. والمتصفّح يُعلمك كلّما شغّلت الإضافة تبويباً.
