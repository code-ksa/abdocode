# Abdo Security — ميزاتُ الحزمة المثبَتة

- **المعرّف**: `abdo-security` · **النوع**: developer · **الإصدار**: 1.0.0
- **الأصل**: أصلٌ لعبدو كود (TechnologyKSA، 2026-09-06). إضافةُ «Claude Security» في المصدر رخصتُها **ملكيّة** (Copyright Anthropic — «All rights reserved»، تمنع النقل والتعديل والاستخدام مع منتجٍ غير أنثروبيك)، فلم يُنقل منها نصٌّ ولا بنية؛ هذه الحزمة تقابلها في الغرض بنصٍّ كتبناه.
- **الاستدعاء**: من الإعدادات ← الامتدادات ← «استخدام في الرسالة التالية»، أو `/skill abdo-security/<المهارة>`

## المهارات (4)

- `/skill abdo-security/security-review` — مراجعةٌ أمنية بعدسات مرتّبة (حقن، تفويض، أسرار، تشفير، تحليل غير آمن، نقل، فشلٌ مغلق) بجدول `خطورة · ملف:سطر · سيناريو · إصلاح` وحكم.
- `/skill abdo-security/secret-scan` — مسحُ الشجرة والتاريخ بأنماط الأسرار وقائمةُ حرقٍ وتدوير بلا طباعة القيم.
- `/skill abdo-security/dependency-audit` — جردُ الاعتمادات من ملفّ القفل، الثغرات، النظافة، الرخص، وتوصيةٌ لكلّ عيب.
- `/skill abdo-security/pre-commit-security` — قائمةُ فحصٍ للفرق المُدرَج قبل الإيداع بحكم GO/NO-GO.

## ما يقابل الأصل وما لا يقابله

- الأصل يعمل بخطّافات (تحذيرٌ عند كلّ تحرير، ومراجعةُ فرقٍ عند التوقّف). عبدو كود لا يشغّل خطّافاتٍ بالتصميم؛ تُستدعى المهارات صراحةً أو من مهارة `pre-commit-security` في مسار الإيداع.
